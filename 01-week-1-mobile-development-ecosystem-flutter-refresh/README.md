## Tujuan

Proyek ini dibuat sebagai latihan awal Pemrograman Mobile untuk memahami ekosistem dan struktur dasar aplikasi Flutter. Aplikasi menampilkan halaman profil mahasiswa sederhana

## Fitur Utama

Menampilkan profil mahasiswa yang terdiri dari nama, NIM, semester, dan informasi mata kuliah.

## Stack Teknologi

- **Flutter 3.47.1** sebagai framework aplikasi lintas platform.
- **Dart 3.13.1** sebagai bahasa pemrograman.
- **Material Design** untuk widget dan tampilan antarmuka.
- **Flutter Test** untuk pengujian widget.
- **Android SDK dan Gradle** untuk membangun aplikasi Android.

## Cara Menjalankan

sambungkan HP pada laptop melalui kabel USB 
lalu jalankan command di terminal 'flutter run'


## Hasil yang Dicapai

- Aplikasi profil mahasiswa berhasil dibuat menggunakan struktur dasar Flutter.
- Antarmuka berhasil menampilkan AppBar, ikon sekolah, nama mahasiswa, NIM, semester, dan informasi mata kuliah.
- Pengujian widget tersedia untuk memastikan seluruh elemen profil tampil dengan benar.
- Proyek dapat dijalankan pada Android maupun browser yang didukung Flutter.

## Kendala Yang Ditemui
Mobile menolak installasi dari USB
