# week9_ai_notes

Aplikasi Flutter untuk Jobsheet Minggu 9: salinan `week7_clean_notes` dengan
fitur pencarian judul catatan dan empty state.

Laporan lengkap, prompt AI, bukti verifikasi, dan screenshot ada di
[`../README.md`](../README.md).

## Menjalankan

```bash
flutter pub get
flutter run -d chrome
```

## Pemeriksaan

```bash
flutter analyze
dart format --output=none --set-exit-if-changed lib test
flutter test
```
