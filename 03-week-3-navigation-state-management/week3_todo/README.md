# Lokasi proyek ToDo

Proyek `week3_todo` telah dipindahkan ke folder induk
`03-week-3-navigation-state-management/` agar `lib/`, `test/`, `docs/`,
dan `screenshots/` berada langsung di folder jobsheet sesuai struktur tugas.

Jalankan `flutter pub get`, `flutter run`, `flutter analyze`, dan `flutter test`
dari folder induk tersebut. Nama package tetap `week3_todo`.
